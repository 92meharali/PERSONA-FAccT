## What we are proposing

An offline study of how a limited number of review slots are allocated among existing AI responses. We compare HumT, response length, a fixed linguistic-marker rule and random selection, then test the incremental contribution of HumT in a fixed trained screen. A common-queue analysis examines the coverage hidden by domain totals. The contribution is comparative allocation under explicit criteria, not another claim that human-likeness predicts appropriateness poorly.

The current draft is [main.tex](../paper/overleaf/main.tex), with a complete [Overleaf package](../releases/PERSONA_FAccT_2027_Overleaf.zip). All four analysis stages reproduced in a fresh environment: 59 numerical tables/figures matched byte for byte. The earlier Markdown draft is historical, not the current manuscript. No source rating or CHI result was changed. Full PDF compilation and layout remain unverified.

## Findings worth assessing

- HumT has useful enrichment for some criterion/domain combinations, but not consistent advantages across criteria.
- A transparent marker baseline can outperform HumT for the D trigger. This also raises target-cue overlap questions: matching rubric language is not independent detection of user harm.
- Stronger D thresholds, consensus rules and sparse supporting prompts change the interpretation. A broad D trigger should not be presented as established serious deception.
- Workload and unreviewed-case reporting expose decisions that regression/ablation does not directly answer, but all underlying responses and judgments are reused from CHI.
- All nine trained incremental intervals include zero; this is not equivalence or universal redundancy.
- General-health markers capture more fit cases overall (32/120 versus 25/120), but fewer natural-prompt fit cases (4/74 versus 8/74). The natural contrast is uncertain: +5.4 pp for HumT, 95% interval -1.3 to +13.0. This illustrates reporting needs, not a proven superior allocation.
