## Prepared local candidate and verified reproduction

`facct/releases/PERSONA_FAccT_Code_Aggregates_REVIEW_CANDIDATE.zip` contains analysis
code, numerical outputs without raw prompt/response text or rater identities, and
generated paper tables. It is extracted and smoke-tested using its own included
standard-library hash/arithmetic checker. Identifying manifests and private records
are excluded. Automated identifier scans are not an anonymity certification; stable
item IDs and underlying content rights still require author review.

omitted raw inputs. Separately, `python -m facct.consolidation.verify --fresh-env`
reran all four stages from the authorized local source in a new environment and an
isolated copy. Every numerical CSV and figure matched: 59 files, 466 seconds.
Do not conflate this internal verification with reproduction from the restricted
candidate. Full anonymous data distribution remains an author-authorized next step.

## Do not include by default

Consent/recruitment forms, identities, payroll or role records, signed institutional letters, public identifying GitHub links, author names in logs, original identifiable manuscript PDFs, full Git history, or unreviewed text-bearing case packets. Private source records stay private. New institutional scope confirmation cannot be supplied by an automated packaging step.

## Acceptance check before distribution

Have an authorized author approve rights/anonymity, then install and rerun from the actual anonymous archive in a fresh directory. Compare generated numerical tables with the frozen originals and document any intentionally excluded input or unavailable historical call. If raw inputs cannot be shared, specify the restriction and supported reproduction level plainly. Do not upload or send an artifact on this checklist's authority.
