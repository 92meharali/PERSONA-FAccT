# Materials included and excluded

## Included

- Full domain-specific scoring protocols and construct anchors
- Anonymous response-level corpus with consensus measurements
- Anonymous rater-level scores needed for reliability analysis
- Active statistical-analysis code and pinned dependencies
- Generated machine-readable tables, reports, and figures
- Ethics, participant-protection, anonymization, and data-handling notes

## Deliberately excluded from anonymous review

| Material | Reason |
|---|---|
| Signed ethics approval | Contains institution, investigator, and committee identities |
| Consent and recruitment records | Contain participant or institutional identifiers |
| Named raw annotation exports | Filenames contain rater identities; the anonymous rating-level export contains the scores required for review |
| Development notebooks with saved outputs | Contain local filesystem paths and execution metadata that can identify contributors |
| API credentials and local environment files | Secret and non-research material |
| Older manuscript and analysis versions | Superseded and liable to conflict with the reported analysis |
| Internal rebuttals, risk notes, and author checklists | Not study materials and not intended for reviewers |

The response-level corpus retains the generated responses and model labels
needed to audit the study. The public post-acceptance artifact should add
cleaned generation scripts and any source materials whose redistribution has
been cleared.
